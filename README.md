# Wayfarer Addons

Free browser add-ons ("userscripts") that add features to **Niantic Wayfarer**, the **Pokémon GO web map**, and the **Ingress Mission Creator**.

## 👉 [Install them here: jeremychuawx.github.io/wayfarer-addons](https://jeremychuawx.github.io/wayfarer-addons/)

The install page walks you through setup, with one-click **Install** buttons and a how-to guide for each add-on. You don't need any technical knowledge.

Problems or ideas? [Open an issue](https://github.com/JeremyChuaWX/wayfarer-addons/issues/new).

## For developers

```
npm install
npm run check   # validate userscript headers + syntax-check every script
npm run serve   # build the site into _site/ and preview it locally
```

- **Userscripts** are the `*.user.js` files in the repo root. When you change one, bump its `@version` so installed copies update.
- **Guides** are in `docs/guides/<script-name>.md`, plus `ticket-manager-sync/README.md` for Ticket Sync. They're rendered into the site.
- **The site** is generated by `scripts/build-site.mjs` from each script's header. A GitHub Action (`.github/workflows/pages.yml`) builds and deploys it on every push to `main`. The build fails if a script's update links don't point at the Pages site.

### Pulling changes from the original repo

```
git fetch upstream
git merge upstream/main
node scripts/fix-metadata.mjs   # re-point @namespace / @downloadURL / @updateURL at this fork
npm run check
```
