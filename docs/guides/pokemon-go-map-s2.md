# Pokémon GO Map: S2 Grids

<!-- summary: Draws the S2 cell grid on the map, so you can see where new PokéStops and Gyms can appear. -->

Draws Pokémon GO's **S2 cell grid** on the official [Pokémon GO map](https://pokemongo.com/gamemap). The grid helps you work out where new PokéStops and Gyms can appear:

- **Level 17 cells** (small, thin **blue** lines): generally only one PokéStop or Gym fits in each.
- **Level 14 cells** (large, thick **red** lines): the number of PokéStops in one of these decides how many Gyms it has.

## How to use it

1. Open the [Pokémon GO map](https://pokemongo.com/gamemap).
2. Zoom in. The **red** level-14 grid appears from zoom level 14.
3. Zoom in further. The **blue** level-17 grid also appears from zoom level 16.
4. The grid updates as you move around. Zoom out and it disappears.

There are no buttons or settings.

**Blue grid looks incomplete?** On very large screens there are too many cells to draw at once, so zoom in one more step.
