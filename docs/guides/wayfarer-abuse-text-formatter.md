# Wayfarer Abuse Text Formatter

<!-- summary: Shows the Wayspot name and location ready to copy into an abuse report while you review. -->

While you review, this shows a ready-made line of text describing the Wayspot. Copy it into Wayfarer's abuse report form, so you don't have to type out the title and coordinates yourself.

## What you'll see

On the **Review** page, a line like this appears just under the big page heading at the top left (**Review**, or **Edit** for edit reviews):

```
"Example Park Bench" at 1.234567,103.456789 [Report]
```

It shows for every kind of review: new Wayspots, photos and edits. When you move on to the next review, the line changes to match.

## How to use it

1. Select the line and copy it.
2. Click **[Report]**. Wayfarer's "Reporting abuse in Wayfarer" help page opens in a **new tab**, so your review stays open.
3. Paste the line into the report form.

There are no settings.

If the line doesn't appear, reload the page. If it still doesn't, check for updates or [report it](https://github.com/JeremyChuaWX/wayfarer-addons/issues/new).
