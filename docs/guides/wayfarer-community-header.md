# Wayfarer Community Header Layout

<!-- summary: Tidies the forum header: flag buttons for English / Japanese, and help links always visible. -->

Tidies the top bar of the [Wayfarer Community forum](https://community.wayfarer.scopely.com/).

## What changes

- The Japanese community link becomes two small **flags**. 🇺🇸 goes to the English forum home page and 🇯🇵 goes to the Japanese community.
- **On a computer:** the main help links (Help Center, abuse reporting, Wayspot removals) are always visible in the header.
- **On a phone:** the header is made more compact so it fits, and some links are hidden.

## How to use it

Install it and use the forum normally. There are no buttons or settings.
